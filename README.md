# QuizDeck

**QuizDeck** is an AI-powered quiz generator that lets you create, upload, and take interactive quizzes in seconds.

**Live app:** [quizdeck.vercel.app/quiz](https://quizdeck.vercel.app/quiz)

---

## Features

- **AI Quiz Generation** — Enter any topic and a question count, and QuizDeck generates a ready-to-take quiz instantly using AI.
- **Upload Your Own Questions** — Import a `.json` file of pre-made questions and jump straight into the quiz.
- **Recent Quizzes** — Your last 10 quizzes are saved locally so you can revisit them anytime with one click.
- **Light / Dark Mode** — Toggle between themes to suit your preference.
- **Animated, Kid-Friendly UI** — Colorful, bouncy interface designed to make learning fun.

---

## How It Works

1. Enter a topic (e.g. *Dinosaurs*, *Space*, *World War II*) and optionally set the number of questions.
2. Hit **Generate** — the AI builds a quiz on the spot.
3. Alternatively, hit **Upload Questions** to load a local `.json` quiz file.
4. Take the quiz, review your results, and replay or generate a new one anytime.

## Tech Stack

- **Next.js** (App Router)
- **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Framer Motion** for animations
- **Anthropic API** for AI question generation
- **Vercel** for deployment
